# Katherine Kuang — Portfolio

Personal portfolio site built with Next.js, based on the "Hairline Glow" hero design.

## Run locally

```sh
npm install
npm run dev
```

Open http://localhost:3000.

## Editing content

All copy, links and image URLs live in `app/content.ts`. Project and profile
images are currently hotlinked from the Squarespace site; to self-host them,
put the files in `public/` and update the `image` / `photo` paths.

## Checks

```sh
npm run lint
npm run build
```
